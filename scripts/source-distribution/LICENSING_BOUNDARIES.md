# Source candidate licensing boundaries

This package preserves original Hub MIT, Stellarium AGPLv3 and third-party
notices/headers. Including connected Hub bridge/protocol/source/build inputs
supports technical source completeness; it does not determine the legal scope
of a combined work or relicense those files. Root THIRD_PARTY_NOTICES.md remains
included. No commercial Stellarium license is presumed. The source offer carries
Stellarium attribution, AGPL text, Hub MIT notice and no-warranty wording.

The pinned upstream native tree itself has notice/provenance gaps requiring
external review before public distribution: inih headers cite a LICENSE.txt not
present in that tree; WebP cites COPYING/PATENTS/AUTHORS not present there; Roboto
font metadata names Apache2 with no standalone matching text; some Noto font
metadata carries copyright but does not establish a redistribution grant.
Those notices are not fabricated from generic library/font names. The package
retains all existing source headers, embedded font metadata and supplied notices.
See ext_src inline notices and Hub font/icon LICENSES.txt files. Source acquisition
of missing notices at proven matching upstream versions and any legal sufficiency
determination remain explicit release gates.

Small bundled Solar imagery and its source provenance, original illustrative
Pennsylvania artwork and font/SVG source assets remain necessary application
build inputs. Their terms are distinct from code licenses. Mounted HiPS/star/TLE
catalogs, lunar surface/orientation releases, planetary ephemerides, user data,
databases and caches are excluded. No new right to mirror or redistribute any
provider data is asserted. Test fixtures remain bounded proof inputs rather than
production catalogs. Earth's pinned upstream SDK/module source is a separately
documented dependency; this qualification does not claim a fresh Earth build.

The distribution is an unpublished engineering candidate. Anonymous public HTTPS
download, prominent offer on an actual public deployment, third-party legal
clearance and physical/owner acceptance must be qualified separately. A passing
archive-only build is evidence about reconstruction, not a legal conclusion.
