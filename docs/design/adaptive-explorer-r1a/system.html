Actions & focus

2 px focus ring + 4 px offset. Tab through controls; Enter activates; Escape dismisses and returns focus. Dialogs keep focus inside until closed.

Icon family

Original inline SVG; 24 px drawing grid, 20 px display, 1.55 px strokes, rounded ends. Every icon-only action has an accessible name and a desktop tooltip.
